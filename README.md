The application consists of 12 Core Modules (9 Citizen-Facing Modules + 3 System & Admin Modules) and 4 Special Utility Tools.
🏛 Part 1: Core Citizen Service Modules (9 Modules)
These are the primary modules accessible to citizens directly from the top navigation bar:
Home Dashboard (home)
Purpose: The central landing dashboard of the portal.
Features: Comprehensive overview of all public digital identity services, trending government initiatives, quick-action cards, live system statistics, and an integrated e-Aadhaar password preview.
Official Portals Directory (portals)
Purpose: Verified directory of official Government of India portals (UIDAI, Income Tax Department, NSDL/Protean, UTIITSL, DigiLocker).
Features: Direct verified official links to protect citizens from phishing/scam websites, clear fee breakdowns, and required document badges.
DigiLocker Complete Guide (digilocker)
Purpose: Visual, step-by-step guide for DigiLocker usage.
Features: Instructions for account creation, linking Aadhaar, setting/resetting the 6-digit security PIN, and issuing digital documents (Class X/XII marksheets, Driving License, Vehicle RC).
Aadhaar Services Guide (aadhaar)
Purpose: Practical guide covering major UIDAI Aadhaar services.
Features: Guidance on new enrolment, name/address/mobile updates, ordering PVC Aadhaar cards, locking/unlocking biometrics for security, and e-Aadhaar PDF downloads.
PAN Card Services Guide (pan)
Purpose: Comprehensive instructions for Income Tax PAN services.
Features: Generating Instant e-PAN (free in 10 minutes), applying for a new physical PAN (Form 49A), making corrections/reprints, and linking PAN with Aadhaar.
Interactive Practice Simulator (simulator)
Purpose: A safe, risk-free training sandbox mimicking official government forms.
Features: Allows citizens to practice entering dummy data, receiving mock OTPs, completing verifications, and downloading simulated official documents without fear of making costly errors.
Requirement & Eligibility Checker (checker)
Purpose: Smart pre-application checklist tool.
Features: Select any service (e.g., address change in Aadhaar, new PAN, DigiLocker setup) to instantly view the required supporting documents, official fees, expected processing time, and important precautions.
FAQ & Citizen Support (faq)
Purpose: Help center and troubleshooting hub.
Features: Categorized FAQs across Aadhaar, PAN, and DigiLocker, instant keyword search, and an interactive support query ticket generator.
Citizen Digital Literacy Quiz (quiz)
Purpose: Interactive assessment tool on digital literacy and cyber safety.
Features: Multi-question quiz assessing citizen knowledge about OTP safety, biometric security, and official procedures, complete with score tracking and certificate/badge generation.
🛡 Part 2: System, Security & Admin Modules (3 Modules)
Authentication & Access Control (AuthPage)
Google Sign-In / Sign-Up: 1-click OAuth authentication.
Email & Password: Secure email-based registration and login backed by Firebase Auth.
Password Recovery: Automated reset link delivery via email.
1-Click Quick Demo Login: Instant auto-fill buttons for "Demo Citizen" and "Super Admin" for rapid testing.
Super Admin Portal (AdminPortal)
(Exclusively accessible to authorized administrators such as sanjeevtiwari5530@gmail.com)
Live Session Monitoring: Real-time log of user sign-ins (timestamp, authentication provider, client device, login status).
Citizen User Registry: Searchable table of registered citizens, role assignment (Citizen vs. Admin), and account management.
Manual User Registration: Form to directly onboard new citizens or administrators from the console.
Audit Trails & Data Export: System-wide security audit logs with instant CSV/Excel export functionality.
Citizen Profile Management (UserProfileModal)
Purpose: Personal account panel.
Features: View profile details (full name, email, account role, last login timestamp) and update account credentials.
⚙️ Part 3: Utility Tools & Accessibility Features (4 Tools)
e-Aadhaar Password Calculator (PasswordTool): Interactive utility that dynamically calculates and explains the 8-character password (first 4 letters of name in capital + 4-digit birth year) needed to unlock downloaded e-Aadhaar PDFs.
Multi-Language Translation Engine: Instant support for 6 Indian Languages (English, Hindi, Bengali, Tamil, Telugu, and Marathi).
Accessibility Control Bar: Font size scaling (A-, A, A+) and high-contrast theme toggle (Black & Yellow) for visually impaired or elderly citizens.
Global Quick Search (Hot-key /): Fast keyboard-driven search modal to instantly navigate to any service, guide, or tutorial across the portal.
